# 요한복음 OBC 강의안 (BEE Korea 교재)

서누리 성인공동체 · 드리머스 청년공동체 요한복음 8주 과정의 강의 PPT를 코드로 생성합니다.
색·폰트·레이아웃을 한 곳에서 관리하므로 2강부터는 **내용만 쓰면** 같은 디자인으로 찍어낼 수 있습니다.

## 결과물

| 강 | 파일 | 슬라이드 |
|---|---|---|
| 제1강 영광을 만나기 위한 준비 (요 1:1~18) | `dist/요한복음_1강_영광을_만나기_위한_준비.pptx` | 60장 |

## 빌드

```bash
npm install          # 최초 1회 (pptxgenjs)
node build.js        # 1강 생성 → dist/
node build.js 01     # 특정 강만 생성
```

빌드하면 글자가 상자를 넘치는 곳을 자동으로 잡아 `⚠ 레이아웃 경고`로 알려줍니다.
경고가 0건이어야 정상입니다.

## 구조

```
build.js                        빌더 진입점
src/theme.js                    디자인 시스템 — 색 · 폰트 · 6개 레이아웃
src/components.js               재사용 부품 — 카드/불릿/인용/흐름도/비교/통계/표
src/apply-theme.js              pptxgenjs 가 못 쓰는 테마 색을 사후 주입
src/lessons/lesson01/
  index.js                      1강 메타(제목·파일명) + 파트 조립
  00-orientation.js             오리엔테이션 + 소그룹 나눔 Ⅰ (1~8)
  10-overview.js                요한복음 전체 분석 (9~24)
  20-part1.js                   1과 전반 · 예수님에 대한 증언 (25~40)
  30-part2.js                   1과 후반 · 하나님에 대한 증언 1:1~18 (41~55)
  40-closing.js                 정리 · 과제 · 부록 (56~60)
```

### 디자인 규칙

- **테마 "영광(Glory)"** — 흰 배경이 전체의 70%, 먹색(`0E1826`)은 섹션 전환·성경 인용·나눔에만,
  금색(`C19A4B`)은 포인트에만 사용.
- **모티프** — 금색 원형 배지. 카드·소제목·흐름도에 반복해서 덱 전체를 하나로 묶는다.
- **레이아웃 6종** — `COVER` / `DIVIDER` / `CONTENT` / `CONTENT_DARK` / `SHARE`(나눔, 네이비) / `TABLE`.
  제목 위치·푸터·쪽번호는 레이아웃이 갖고 있으므로 슬라이드마다 따로 넣지 않는다.
- **폰트** — 맑은 고딕. 제목 32pt / 소제목 17~20pt / 본문 13~16pt.

색을 바꾸려면 `src/theme.js` 의 `THEME.colors` 만 고치면 전체 덱에 반영됩니다.

## 2강 이후 추가하는 법

1. `src/lessons/lesson02/` 를 만들고 `lesson01` 의 파일들을 복사해 내용을 교체
2. `src/lessons/lesson02/index.js` 에 `id` · `title` · `fileName` 지정
3. `build.js` 의 `LESSONS` 에 `"02": require("./src/lessons/lesson02")` 추가
4. `node build.js 02`

## 1강 진행 순서 (60장)

| 구간 | 슬라이드 | 내용 |
|---|---|---|
| 오리엔테이션 | 1~7 | 인사 · 오늘의 흐름 · 8주 과정 · 수료 기준 · 진행 순서 · 강의 방향 |
| 소그룹 나눔 Ⅰ | 8 | 자기소개 · 수강 계기 · **조장 선출** |
| 요한복음 분석 | 9~24 | 저자/기록목적/구조 3종/완전수 7 네 가지/21장 조망/특수자료/암기 보드 |
| 1과 전반 | 25~40 | 가. 사도 요한 ~ 바. 기록목적 (교재 질문 1~21) |
| 1과 후반 | 41~55 | 창조주 · 인도자 · 하나님이신 예수님 (교재 질문 22~41) |
| 마무리 | 56~58 | 1강 한 장 정리 · 다음 주 과제 · 맺음 |
| 부록 | 59~60 | 성령의 상징/시간 시리즈/안식일 치유 · 14장 Q&A/부활 현현 |

시간이 부족하면 **부록(59~60)과 21장 조망(21~22)** 을 건너뛰고, 암기 보드(24)는 2주차 복습으로 미루세요.

나눔 슬라이드(네이비 배경)는 8 · 32 · 35 · 40 · 46 · 50 · 55 번입니다.
